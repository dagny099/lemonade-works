# Lemonade Works

A hands-on learning project about AI judgment, Skills, workflows, agents,
information quality, and governance, taught through the growth of a fictional
lemonade business.

## Current phase

Stage 0: personal baseline and Skill experiment.

## Start here

1. Open `stage-0/participant/BRIEFING.html`.
2. Complete the pre-commitment.
3. Paste it into `stage-0/experiments/run-001/FINDINGS-LOG.md`.
4. Investigate only the files in `stage-0/corpus/`.
5. Do not open `stage-0/private/ANSWER-KEY.md` until findings are frozen.

## Repository areas

- `design/` — instructional design and project rationale
- `stage-0/corpus/` — fictional business records
- `stage-0/participant/` — participant-facing materials
- `stage-0/experiments/` — run logs, outputs, and screenshots
- `stage-0/private/` — sealed evaluation materials
